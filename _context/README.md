# Kustos context

Keep current, Kustos-specific operational facts here when they help agents
work effectively: for example, people and roles, recurring dates, preferences,
or active external relationships. Organize notes in the shape that best fits
the project; this foundation intentionally does not prescribe a schema.

This directory is Git-tracked project context, not a place for credentials or
other secrets. It is separate from immutable Raw material and curated Wiki
knowledge: it is not exposed by the Wiki MCP and does not become authoritative
Wiki knowledge without deliberate curation into `wiki/`.

Use `.agents/skills/context/SKILL.md` when reading or maintaining this area.
