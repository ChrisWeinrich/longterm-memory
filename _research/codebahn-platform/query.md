# Deep research query

Research this question: Eignet sich Codebahn als europäisch souveräner Ersatz
für GitHub samt Repos, Issues und CI/CD, und welche dokumentierten
Schnittstellen gibt es für CLI, MCP und Coding-Agenten?

Use the accepted outline as the scope. Prefer Codebahn legal, security, API,
CLI, MCP and CI documentation; then Forgejo upstream documentation for shared
behaviour; use independent sources only as labelled context. Verify all claims
about European jurisdiction, subprocessors, runner region/isolation, workflow
compatibility, authentication, permissions, data export, and agent execution.
Distinguish a platform that exposes MCP/CLI to an external agent from an actual
hosted coding-agent runtime. Record source URLs, publication dates when
available, evidence, uncertainty, and inference separately.
