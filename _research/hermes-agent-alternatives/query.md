# Deep research query

Research this question: Ist Hermes Agent für einen ersten privaten,
Tailscale-only erreichbaren Vault-Agenten mit Obsidian-Markdown als
Wissensquelle die beste Runtime, oder bieten LibreChat, Letta, Open WebUI oder
eine schlanke Eigenarchitektur einen klaren, sicherheitsrelevanten Vorteil?

Use the accepted outline as the scope. Prefer original and official sources,
then peer-reviewed research, then reputable secondary analysis for context.
Record source URLs, publication dates when available, evidence, uncertainty,
and any inference separately from sourced facts.

Verify in particular: network exposure and authentication; MCP client and
server capabilities; API, sessions, task status and logging; memory and
backups; the boundary between agent state and the existing read-only Wiki MCP;
and the least-privilege MVP configuration. Treat changing product behavior as
time-sensitive and record the retrieval date.

Write the completed report to `_raw/research/hermes-agent-alternatives/report.md`
from `_templates/raw-research-report.md`. It is Raw material without a state
and is curated into `wiki/pages/` later.
