# OpenHands Coding-Agent Platform

## Question

What can the current OpenHands platform do for local-first and cloud coding-agent
work, where does it fit in a deterministic Go-task control plane, and which
alternatives provide comparable capabilities?

## Decision and audience

Decision-ready briefing for an engineering owner using Codex APIs, GitHub
Copilot, GitHub Actions, macOS and an existing Go task system.

## Scope

OpenHands architecture, local and cloud execution, sandboxes, workspaces,
models and ACP agents, automation, GitHub integration, task lifecycle,
observability, permissions, security boundaries, deterministic-pipeline fit,
and alternatives in the categories control plane, coding-agent runtime and
durable workflow engine.

## Exclusions

Hands-on installation, benchmark replication, price comparison, production
deployment design, and unverified claims about plan-specific availability.

## Success criteria

Explain the actual capability boundary; recommend a minimal integration shape
with the Go task system; identify risks and a bounded trial; distinguish
OpenHands from alternatives rather than producing a feature list.
