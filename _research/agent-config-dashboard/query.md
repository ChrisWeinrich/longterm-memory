# Deep research query

Research this question: Which existing locally or privately operated tools are
suited to inventory coding agents and their configuration on a Mac, and show a
redacted source-versus-live comparison between ChezMoi and runtime state; and
which gaps justify a small, custom read-only collector and viewer?

Use the accepted outline as the scope. Prefer original and official sources,
then peer-reviewed research, then reputable secondary analysis for context.
Record source URLs, publication dates when available, evidence, uncertainty,
and any inference separately from sourced facts.

Verify in particular: agent and configuration coverage; discovery and
inspection of MCP servers, skills, instructions, and permissions; local
execution and network exposure; redaction and secret boundaries; ChezMoi or
Dotfiles integration; licensing, maturity, and maintenance effort. Treat
product capabilities and pricing as time-sensitive and record the retrieval
date.

Write the completed report to `_raw/research/agent-config-dashboard/report.md`
from `_templates/raw-research-report.md`. It is Raw material without a state
and is curated into `wiki/pages/` later.
